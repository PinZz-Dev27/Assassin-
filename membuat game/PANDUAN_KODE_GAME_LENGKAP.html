🏛️ 1. Arsitektur Proyek dan Aliran Data

Pure Vanilla JS • No External Engine

Bagaimana Ketiga File Inti Berkomunikasi?

Game ini dibangun murni tanpa framework pihak ketiga (tanpa Phaser, Pixi, atau Unity). Seluruh engine rendering, engine fisika 2D, generator audio sintetis, dan AI algoritma ditulis mandiri dengan arsitektur Separation of Concerns (Pemisahan Peran):

Nama Berkas Peran Utama Entitas Kunci yang Ditangani
index.html Florence Guild HQ (Lobby & Manajemen) Toko kostum ninja, pemilihan senjata (Katana, Dagger, Saber), upgrade skill stamina, daftar quest harian, pemilihan stage, dan saldo koin/diamond.

📌 Jembatan Memori Bersama: Web Storage API (`localStorage`)
Ketika pemain memilih kostum emas, senjata saber, dan tahap 3 di lobi (index.html), data disimpan ke disk browser menggunakan localStorage.setItem('ninjaSkin', 'emas'). Saat tombol "DEPLOY" diklik, halaman dialihkan ke game.html, lalu game.js membaca konfigurasi tersebut pada fungsi resetGame().

📘 2. Sintaks Spesifik JavaScript & Optimasi Memori

ES6+ Standards

Aturan Variabel: `const` vs `let` (Tanpa `var`)

Di dalam game.js terdapat pemisahan tegas penggunaan kata kunci variabel:

  • const: Digunakan untuk nilai konstan yang tidak boleh bermutasi, misalnya dimensi peta (KOLOM_NAV = 50, BARIS_NAV = 35), referensi elemen kanvas tetap, dan rumus trigonometri tetap.
  • let: Digunakan untuk variabel dinamis yang berganti nilai setiap frame (koordinat X/Y pemain, bar stamina, timer cooldown, dan loop iterator).
  • Ditinggalkannya var: Mencegah hoisting bug dan kebocoran variabel ke luar kurung kurawal (Block Scope terjamin).

Struktur Data Biner Efisien: `Uint8Array`

Untuk menyimpan status keterhalangan grid peta arena navigasi AI (50 x 35 = 1750 sel):

let kisiNavigasi = new Uint8Array(KOLOM_NAV * BARIS_NAV);

Keunggulan Teknis:
Tiap sel hanya memakan 1 byte memori fisik (angka 0 = bebas, angka 1 = tembok). Dibandingkan array objek biasa [], Uint8Array tidak memicu Garbage Collection Stutter di tengah perhitungan ribuan evaluasi A*.

🧱 3. Sistem Tembok, Collision & Raycasting

AABB • Anti-Nyangkut • Slab Method

Fisika Tembok 1. Struktur Data Tembok & Deteksi Tabrakan (AABB vs Circle)

Tembok di seluruh stage didefinisikan sebagai daftar balok persegi panjang dalam koordinat piksel 2D:

// Format definisi objek tembok di data level:
tembok = [
  { x: 120, y: 80,  w: 160, h: 24 },
  { x: 340, y: 180, w: 24,  h: 220 },
  { x: 500, y: 140, w: 180, h: 24 }
];

Fungsi deteksi tabrakan cekTabrakanTembok(posisiX, posisiY, radius) mengecek perpotongan antara lingkaran entitas (pemain, musuh, atau proyektil) terhadap seluruh balok AABB (Axis-Aligned Bounding Box):

function cekTabrakanTembok(posisiX, posisiY, radius) {
  for (let t of tembok) {
    if (posisiX + radius > t.x && 
        posisiX - radius < t.x + t.w && 
        posisiY + radius > t.y && 
        posisiY - radius < t.y + t.h) {
      return true; // Terjadi benturan dengan tembok ini
    }
  }
  return false; // Ruang bebas tanpa halangan
}
  • Perluasan Kotak (Box Expansion): Logika posisiX + radius > t.x dan posisiX - radius < t.x + t.w secara matematis memperluas batas kotak tembok sebesar radius lingkaran di setiap sisi, memungkinkan pengecekan Overlap Interval super cepat dalam mikrodetik.

Anti-Stuck 2. Pembebasan Entitas (`bebaskanMusuhDariTembok`)

Mencegah karakter atau boss tersangkut saat terdorong knockback atau berbelok sempit:

function bebaskanMusuhDariTembok(m) {
  for (let iter = 0; iter < 2; iter++) {
    let collided = false;
    for (let t of tembok) {
      if (m.x + m.radius > t.x && m.x - m.radius < t.x + t.w &&
          m.y + m.radius > t.y && m.y - m.radius < t.y + t.h) {
        collided = true;
        let dKiri  = (m.x + m.radius) - t.x;
        let dKanan = (t.x + t.w) - (m.x - m.radius);
        let dAtas  = (m.y + m.radius) - t.y;
        let dBawah = (t.y + t.h) - (m.y - m.radius);
        let minD = Math.min(dKiri, dKanan, dAtas, dBawah);

        // Dorong keluar menuju sisi terdekat + 0.5px buffer
        if (minD === dKiri)       m.x = t.x - m.radius - 0.5;
        else if (minD === dKanan) m.x = t.x + t.w + m.radius + 0.5;
        else if (minD === dAtas)  m.y = t.y - m.radius - 0.5;
        else if (minD === dBawah) m.y = t.y + t.h + m.radius + 0.5;
      }
    }
    if (!collided) break;
  }
}

Raycast Optik 3. Penembus Garis Sinar (`hitRayWall`)

Digunakan oleh senter musuh dan laser cctv untuk mendeteksi dinding penghalang:

// Algoritma Slab Method (Line-AABB Intersection)
function hitRayWall(asalX, asalY, arahX, arahY, jarakMaksimal) {
  let jarakTerdekat = jarakMaksimal;
  for (let i = 0; i < tembok.length; i++) {
    let t = tembok[i];
    // Hitung tMin dan tMax untuk sumbu X dan Y
    let invDirX = 1 / (arahX !== 0 ? arahX : 0.00001);
    let invDirY = 1 / (arahY !== 0 ? arahY : 0.00001);
    let t1 = (t.x - asalX) * invDirX;
    let t2 = (t.x + t.w - asalX) * invDirX;
    let t3 = (t.y - asalY) * invDirY;
    let t4 = (t.y + t.h - asalY) * invDirY;
    let tMin = Math.max(Math.min(t1, t2), Math.min(t3, t4));
    let tMax = Math.min(Math.max(t1, t2), Math.max(t3, t4));
    if (tMax >= 0 && tMin <= tMax && tMin < jarakTerdekat) {
      if (tMin >= 0) jarakTerdekat = tMin;
    }
  }
  return jarakTerdekat;
}

Visual Tembok 4. Rendering 2.5D Pseudo-Depth pada Kanvas

Tembok digambar dengan efek kedalaman bayangan dan sudut bevel sesuai tema map aktif:

// Pada draw() di game.js:
ctx.shadowColor = 'rgba(0,0,0,0.7)';
ctx.shadowBlur = 8;
ctx.shadowOffsetX = 3;
ctx.shadowOffsetY = 3;

for (let t of tembok) {
  if (temaPeta === "lab") {
    ctx.fillStyle = warnaAtasTembok; // #1a252f
    ctx.fillRect(t.x, t.y, t.w, t.h);
    ctx.strokeStyle = warnaTembok;    // Neon Cyan #00e5ff
    ctx.lineWidth = 2.5;
    ctx.strokeRect(t.x, t.y, t.w, t.h);
  } else {
    // Sisi samping gelap (dasar)
    ctx.fillStyle = warnaTembok;
    ctx.fillRect(t.x, t.y, t.w, t.h);
    // Atap tembok lebih terang dengan inset bevel 2px
    ctx.shadowColor = 'transparent';
    ctx.fillStyle = warnaAtasTembok;
    ctx.fillRect(t.x + 2, t.y + 2, t.w - 4, t.h - 4);
  }
}

🚶 4. Mekanika Berjalan (Walking)

WASD • Vektor Diagonal • Wall Sliding

Input & Kinematika Logika Gerak Berjalan Mulus

Ketika pemain menekan tombol [W], [A], [S], [D], sistem membaca status input dan menghitung vektor pergerakan terarah:

let currentSpeed = pemain.kecepatanNormal; // Nilai bawaan: 3.8 px/frame
let inputX = 0, inputY = 0;

if (statusTombol.w) inputY -= 1;
if (statusTombol.s) inputY += 1;
if (statusTombol.a) inputX -= 1;
if (statusTombol.d) inputX += 1;

// 1. Normalisasi Gerakan Diagonal (PENTING!)
if (inputX !== 0 && inputY !== 0) {
  inputX *= 0.7071; // 1 / sqrt(2)
  inputY *= 0.7071;
}

let targetVx = inputX * currentSpeed;
let targetVy = inputY * currentSpeed;

// 2. Akselerasi Halus (Smooth Interpolation)
let kecepatanInterpolasi = 0.28;
pemain.vx = (pemain.vx || 0) + (targetVx - (pemain.vx || 0)) * kecepatanInterpolasi;
pemain.vy = (pemain.vy || 0) + (targetVy - (pemain.vy || 0)) * kecepatanInterpolasi;
  • Mengapa dikalikan 0.7071? Tanpa pengali ini, jika pemain menekan [W] dan [D] bersamaan, vektor kecepatan resultan menjadi $\sqrt{1^2 + 1^2} = 1.414$ (+41.4% lebih cepat). Dengan pengali $1/\sqrt{2} \approx 0.7071$, kecepatan diagonal tetap tepat 100% konsisten.
  • Senyap Sempurna: Saat berjalan normal, pemain.noiseR = 0. Karakter ninja melangkah tanpa mengeluarkan suara derap, sehingga musuh yang membelakangi pemain tidak akan sadar akan kedatangan Anda.

Wall Sliding (Meluncur di Sisi Tembok)

Agar ninja tidak macet saat berjalan menabrak sudut tembok secara menyerong, pergerakan sumbu X dan Y dipisahkan secara independen:

// Gerak sumbu X terlebih dahulu
pemain.x += pemain.vx;
if (cekTabrakanTembok(pemain.x, pemain.y, pemain.radius)) {
  pemain.x -= pemain.vx; // Batalkan hanya sumbu X
  pemain.vx = 0;
}

// Gerak sumbu Y secara terpisah
pemain.y += pemain.vy;
if (cekTabrakanTembok(pemain.x, pemain.y, pemain.radius)) {
  pemain.y -= pemain.vy; // Batalkan hanya sumbu Y
  pemain.vy = 0;
}

Hasil: Jika pemain menekan [W]+[D] ke dinding vertikal, sumbu X ditahan nol namun sumbu Y tetap bergerak bebas, membuat ninja meluncur mulus ke atas di sepanjang dinding.

Rotasi 360° & Kemiringan Tubuh (Dynamic Lean)

Perputaran arah hadap dihitung secara matematis menggunakan arkus tangen dan interpolasi sudut linier:

let sudutTarget = Math.atan2(pemain.vy, pemain.vx);
pemain.visualSudut = lerpAngle(pemain.visualSudut, sudutTarget, 0.26);

// Efek tubuh miring lincah saat bermanuver
let targetKemiringan = (pemain.arah === 'kiri' ? -0.1 : (pemain.arah === 'kanan' ? 0.1 : 0));
pemain.leanAngle = (pemain.leanAngle || 0) + (targetKemiringan - (pemain.leanAngle || 0)) * 0.18;

Fungsi lerpAngle menyelesaikan anomali loncatan rotasi dari $-\pi$ ke $+\pi$ ($359^\circ$ ke $0^\circ$), menghasilkan perputaran tubuh yang elastis dan realistis.

🏃 5. Mekanika Lari & Konsumsi Stamina

Shift Key • Noise Radius • Stamina Gauge

Sistem Sprint Mekanisme Berlari (Lari Kencang dengan Tombol Shift)

Ketika pemain menahan tombol [Shift] sambil menekan tombol arah gerak, ninja beralih dari mode jalan senyap menjadi mode lari berkecepatan tinggi:

let adaInputGerakan = statusTombol.w || statusTombol.s || statusTombol.a || statusTombol.d;

if (statusTombol.shift && pemain.energiDash > 0 && adaInputGerakan) {
  if (!sedangNgedash) {
    mainkanSuara('dash'); // Memicu audio derap lari kencang
    sedangNgedash = true;
  }
  currentSpeed = pemain.kecepatanDash; // Kecepatan meningkat dari 3.8 -> 7.6 px/frame
  pemain.energiDash -= 2.2;            // Menguras stamina per frame
  pemain.noiseR = 150;                 // Memancarkan gelombang suara derap kaki 150px!
  picuSuara(pemain.x, pemain.y, pemain.noiseR);
} else {
  sedangNgedash = false;
  // Regenerasi stamina saat tidak berlari / tombol dilepas
  if (pemain.energiDash < 100) pemain.energiDash += 0.65;
}
Kondisi Bergerak Kecepatan Konsumsi Stamina Radius Suara (Noise Radius) Reaksi Musuh di Sekitar
Berjalan (Walk) 3.8 px/frame 0 (Stamina pulih +0.65/f) 0 px (Hening mutlak) Musuh tenang, tidak mendengar derap langkah apapun.
Berlari (Sprint / Dash) 7.6 px/frame (+100%) -2.2 unit/frame 150 px (Derap keras) Musuh dalam jarak 150px langsung kaget, berubah ke mode investigate dan berbalik memeriksa!
⚠️ Risiko Taktis: Suara Derap Kaki (`picuSuara`)
Fungsi picuSuara(pemain.x, pemain.y, 150) memeriksa seluruh musuh di arena: 
function picuSuara(x, y, radius) {
  for (let m of musuh) {
    if (Math.hypot(x - m.x, y - m.y) < radius) {
      m.status = "investigate";
      m.targetX = x;
      m.targetY = y;
      m.alertTimer = 180; // Waspada mencari selama 3 detik
    }
  }
}
Gunakan lari cepat hanya untuk melintasi lorong terbuka atau mengejar musuh yang sedang membelakangi Anda!

⚡ 6. Sistem Dash & Efek Bayangan (Afterimage)

Afterimage Trail • Lerp Response • Frame Animation

Visual Effect Merekam Jejak Bayangan Ninja

Saat berlari kencang/dash, sistem merekam snapshot posisi tubuh setiap 3 frame ke dalam antrian bayangan:

if (sedangNgedash && sedangBergerak) {
  pemain.state = 'dash';
  pemain.animFrame = Math.floor(penghitungBingkai / 4) % 4;

  if (penghitungBingkai % 3 === 0) {
    let kunciBaju = petaWarnaBaju[warnaPemain] || 'navy';
    let gambarSprite = asetGame.spritesheets[kunciBaju];
    let sData = DATA_LEMBAR_SPRITE[kunciBaju];
    let sRect = sData.walk[3];

    pemain.trail.push({
      x: pemain.x,
      y: pemain.y,
      sudut: pemain.visualSudut,
      alpha: 0.45,
      sRect: sRect,
      gambarLembarSprite: gambarSprite
    });
    if (pemain.trail.length > 5) pemain.trail.shift();
  }
}

Pemudaran & Responsivitas Kemudi

Setiap frame di update(), nilai transparansi bayangan dikurangi secara berkala:

// Reduksi opacity bayangan afterimage
pemain.trail.forEach(t => t.alpha -= 0.05);
pemain.trail = pemain.trail.filter(t => t.alpha > 0);

// Akselerasi kemudi lebih tajam saat dash
let kecepatanInterpolasi = sedangNgedash ? 0.38 : 0.28;
pemain.vx += (targetVx - pemain.vx) * kecepatanInterpolasi;
pemain.vy += (targetVy - pemain.vy) * kecepatanInterpolasi;

Koefisien interpolasi dinaikkan ke 0.38 saat dash, memberikan rasa kemudi drift ninja yang sangat lincah dan responsif saat bermanuver menghindari peluru.

🗡️ 7. Efek Slash, Katana Melee & Rapid Slashes

Canvas Arc Slash • Cooldown Limiter • Flurry 3-Bar HP

Tebasan Reguler 1. Eksekusi Tebasan Melee (Tombol [L] / `bunuhMusuh`)

Mekanisme serangan pisau/katana dibatasi maksimal 2 kali tebasan berturut-turut untuk menjaga keseimbangan permainan:

function bunuhMusuh() {
  if (window.gameState !== "playing") return;

  // 1. Cek Apakah Sedang Cooldown
  if (pemain.slashCooldown > 0) {
    let sisa = (pemain.slashCooldown / 60).toFixed(1);
    munculkanTeks(pemain.x, pemain.y - 20, `COOLDOWN! (${sisa}s)`, "#ef4444");
    mainkanSuara('block');
    return;
  }

  // 2. Konsumsi Kuota Tebasan (Maksimal 2x)
  pemain.slashCharges = (pemain.slashCharges !== undefined) ? pemain.slashCharges - 1 : 1;
  if (pemain.slashCharges <= 0) {
    pemain.slashCooldown = 120; // 2 Detik Cooldown (120 frame pada 60 FPS)
    pemain.slashCharges = 0;
  } else {
    pemain.slashResetTimer = 90; // Jeda 1.5s untuk reset kuota jika tidak lanjut menebas
  }

  pemain.state = 'serang';
  pemain.actionTimer = 18;

  // 3. Tambahkan Objek Efek Slash ke Array
  daftarTebasan.push({
    x: pemain.x + Math.cos(pemain.sudut) * 20,
    y: pemain.y + Math.sin(pemain.sudut) * 20,
    sudut: pemain.sudut,
    frame: 0
  });
  mainkanSuara('slash');
  // Lanjut ke pemeriksaan benturan hitbox musuh (Radius 75px)...
}

Canvas Rendering 2. Menggambar Busur Tebasan Sabit

Busur tebasan katana dirender pada draw() dengan membesarkan radius lingkaran sembari memudarkan ketebalan garis:

for (let s of daftarTebasan) {
  ctx.save();
  ctx.translate(s.x, s.y);
  ctx.rotate(s.sudut);
  ctx.beginPath();
  // Busur sabit melingkar dari -120 derajat ke +120 derajat
  ctx.arc(0, 0, 36 + s.frame * 1.5, -Math.PI / 1.5, Math.PI / 1.5);
  ctx.lineWidth = 7 * (1 - s.frame / 15);
  ctx.globalAlpha = 1 - (s.frame / 15);
  ctx.strokeStyle = warnaSenjata;
  // Jika senjata berjenis Cyber Saber, beri efek glow neon
  if (tipeSenjata === "bentuk-saber") {
    ctx.shadowColor = "#00e5ff";
    ctx.shadowBlur = 15;
  }
  ctx.stroke();
  ctx.restore();
}

Ultimate Slash 3. Skill Rapid Slash (Tombol [R] / -3 Bar HP)

Serangan pedang bertubi-tubi kilat selama 2 detik penuh yang mengiris 3 Bar HP musuh/boss:

// Di update() saat pemain.rapidActive aktif:
pemain.rapidTimer--;

// Munculkan flurry tebasan acak setiap 6 frame
if (pemain.rapidTimer % 6 === 0) {
  let randA = pemain.sudut + (Math.random() - 0.5) * 1.6;
  daftarTebasan.push({
    x: pemain.x + Math.cos(randA) * 25,
    y: pemain.y + Math.sin(randA) * 25,
    sudut: randA,
    frame: 0
  });
  playTone('sawtooth', 380 + Math.random() * 260, 180, 0.08, 0.18);
  getarLayar = 5;
}

// 3 Pukulan Fatal berurutan pada frame 100, 60, dan 20
if (pemain.rapidTimer === 100 || pemain.rapidTimer === 60 || pemain.rapidTimer === 20) {
  for (let m of musuh) {
    if (Math.hypot(pemain.x - m.x, pemain.y - m.y) < 115) {
      m.hp--; // Potong 1 Bar HP per pukulan
      m.stunTimer = 18;
      munculkanTeks(m.x, m.y - 15, "-1 BAR HP!", "#f59e0b");
      getarLayar = 12;
    }
  }
}

🎯 8. Sistem Tembakan & Proyektil (Shooting)

Shuriken • Kunai Fan • Enemy Tracer Bullets • Boss Cannon

Pemain: Jarak Jauh 1. Lemparan Bintang Ninja Shuriken (`lemparShuriken`)

Pemain dapat menembakkan shuriken jarak jauh (Tombol [K] atau Klik Kanan) menggunakan kuota amunisi terbatas:

function lemparShuriken() {
  if (window.gameState !== "playing" || pemain.ammo <= 0) return;
  pemain.ammo--; // Amunisi berkurang
  pemain.state = 'serang';
  pemain.actionTimer = 12;

  daftarShuriken.push({
    x: pemain.x,
    y: pemain.y,
    dx: Math.cos(pemain.sudut) * 13, // Melaju kencang 13 px/frame
    dy: Math.sin(pemain.sudut) * 13,
    rot: 0
  });
  mainkanSuara('shuriken');
}

Di fungsi update(), lintasan dan tabrakan shuriken dihitung secara fisik:

  • Perputaran Visual: s.rot += 0.5 setiap frame menghasilkan visual bintang berputar di udara.
  • Tabrakan Tembok: cekTabrakanTembok(s.x, s.y, 5) memicu denting logam, memercikkan partikel abu-abu, dan suara pantulan picuSuara(s.x, s.y, 180) yang memancing musuh.
  • Penetralan Musuh: Shuriken memberikan damage 1 HP dan knockback 20px pada keroco biasa. Namun jika mengenai perisai depan musuh Juggernaut atau ditepis oleh Rival Assassin, proyektil terpental mental (Deflected).

Musuh: Peluru Senapan 2. Peluru Musuh (Hunter Tracer Bullets)

Musuh bersenjata pistol dan Boss menembak pemain saat status waspada (Chase):

// Musuh menembakkan peluru dari ujung moncong laras:
let sudutPeluru = Math.atan2(pemain.y - m.y, pemain.x - m.x) + (Math.random() - 0.5) * 0.1;
let ujungMoncongX = m.x + Math.cos(m.sudut) * (m.radius + 14);
let ujungMoncongY = m.y + Math.sin(m.sudut) * (m.radius + 14);
let tembakanBoss = (m.tipe === "boss");

daftarPeluruMusuh.push({
  x: ujungMoncongX,
  y: ujungMoncongY,
  vx: Math.cos(sudutPeluru) * (tembakanBoss ? 11.5 : 9.8),
  vy: Math.sin(sudutPeluru) * (tembakanBoss ? 11.5 : 9.8),
  life: 85,
  isBoss: tembakanBoss,
  damage: tembakanBoss ? 6 : 4
});

  let jY = pemain.y - m.y;
  let jTot = Math.hypot(jX, jY);

  // 2. Di luar jangkauan jarak senter (240px)? -> Lolos
  if (jTot > JARAK_PANDANG) return false;

  // 3. Di luar sudut kerucut pandang (+/- 35 derajat)? -> Lolos
  let sPemain = Math.atan2(jY, jX);
  let selisih = Math.abs(sPemain - m.sudut);
  if (selisih > Math.PI) selisih = 2 * Math.PI - selisih;
  if (selisih > LEBAR_PANDANG) return false;

  // 4. Apakah ada dinding yang memutus garis pandang?
  let hitDist = hitRayWall(m.x, m.y, jX / jTot, jY / jTot, jTot);
  return hitDist >= jTot - 5;
}

Bagaimana Suara Dihasilkan Tanpa File Audio Eksternal?

Game ini 100% bebas dari unduhan file MP3/WAV. Seluruh efek suara dirancang menggunakan modulasi frekuensi gelombang matematis:

function playTone(tipeGelombang, frekuensiAwal, frekuensiAkhir, durasi, nilaiPenguat = 0.3) {
  if (!konteksAudio) return;
  let waktuSekarang = konteksAudio.currentTime;
  let osilator = konteksAudio.createOscillator();
  let nodePenguat = konteksAudio.createGain();

  osilator.type = tipeGelombang; // 'sine', 'sawtooth', 'triangle', 'square'
  osilator.frequency.setValueAtTime(frekuensiAwal, waktuSekarang);
  osilator.frequency.exponentialRampToValueAtTime(frekuensiAkhir, waktuSekarang + durasi);

  nodePenguat.gain.setValueAtTime(nilaiPenguat, waktuSekarang);
  nodePenguat.gain.exponentialRampToValueAtTime(0.001, waktuSekarang + durasi);

  // Sambungkan kabel virtual: Oscillator -> Gain -> Speaker Komputer
  osilator.connect(nodePenguat);
  nodePenguat.connect(konteksAudio.destination);

  osilator.start(waktuSekarang);
  osilator.stop(waktuSekarang + durasi);
}
Efek Suara Bentuk Gelombang Frekuensi Awal & Akhir Sensasi Suara yang Dihasilkan
Tebasan Katana (Slash) sawtooth 380 Hz ➔ 70 Hz (0.15s) Suara gesekan pisau tajam membelah udara.
Dash Sprint triangle 240 Hz ➔ 60 Hz (0.2s) Suara deru angin cepat saat ninja melesat.

Q1 Mengapa kamu memilih `let` dan `const` dibandingkan `var` di seluruh skrip?
▼
Kunci Jawaban Ideal:

"`let` dan `const` adalah fitur modern ECMAScript 6 yang menganut aturan Block Scope. Variabel yang dideklarasikan dengan keduanya hanya hidup di dalam kurung kurawal tempat dibuatnya, mencegah kebocoran nilai atau tertimpa tanpa sengaja di luar perulangan. `const` saya gunakan untuk nilai konstan yang tidak boleh bermutasi seperti ukuran grid navigasi atau referensi kanvas, sedangkan `let` digunakan untuk variabel yang berubah setiap frame seperti koordinat X/Y dan stamina. Sebaliknya, `var` sudah ditinggalkan karena bersifat Function Scope dan rentan memicu bug akibat hoisting."
